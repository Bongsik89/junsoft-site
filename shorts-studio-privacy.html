Shorts Studio
개인정보처리방침

Jun Soft는 Shorts Studio 사용자의 개인정보와 로컬 프로젝트 데이터를 중요하게 생각합니다. 이 문서는 Shorts Studio가 어떤 데이터를 처리하고, 어떻게 보호하는지 설명합니다.

시행일: 2026-10-07 운영자: Jun Soft (준 소프트) 문의: jaejun@junsoftdev.kr

1. 적용 범위

본 개인정보처리방침은 Jun Soft가 제공하는 Windows 데스크톱 애플리케이션 Shorts Studio에 적용됩니다.

2. Jun Soft가 수집하는 개인정보

현재 Shorts Studio는 서비스 이용을 위해 사용자 계정 생성이나 로그인을 요구하지 않으며, Jun Soft가 운영하는 별도 서버로 사용자의 이름, 주소, 전화번호, 연락처 목록 등의 개인정보를 자동 수집하도록 설계되어 있지 않습니다.

또한 Shorts Studio에는 Jun Soft가 운영하는 광고 추적 기능이나 사용자 행동 분석을 위한 별도 텔레메트리 시스템을 기본적으로 포함하지 않습니다.

3. 사용자가 선택한 파일 및 프로젝트 데이터

Shorts Studio는 영상 제작 및 품질 확인 기능을 제공하기 위해 사용자가 직접 선택한 파일을 처리할 수 있습니다.

  • 이미지 및 사진 파일
  • 영상 파일
  • 음성 및 오디오 파일
  • 자막, 프로젝트 설정, 제작 과정에서 생성되는 관련 파일

이러한 파일은 사용자가 요청한 편집, 렌더링, 분석, 품질 확인 등의 작업을 수행하기 위해 사용자의 PC에서 처리됩니다. Jun Soft는 해당 파일의 소유권을 주장하지 않습니다.

4. AI 기능 및 로컬 처리

Shorts Studio에는 AI를 활용한 제작 보조 및 품질 확인 기능이 포함될 수 있습니다. 로컬 AI 기능을 사용하는 경우, 해당 처리는 사용자의 PC에서 실행되는 로컬 모델 또는 로컬 서비스(예: Ollama)를 통해 수행될 수 있습니다.

로컬 처리 기능에서 사용되는 프로젝트 파일은 해당 기능을 수행하기 위한 목적으로 사용자의 장치 내에서 처리됩니다.

사용자가 별도의 외부 서비스 또는 제3자 도구를 직접 이용하는 경우에는 해당 서비스의 개인정보처리방침과 이용약관이 적용될 수 있습니다.

5. 데이터 저장 및 보관

프로젝트 파일, 설정, 렌더링 결과물 및 작업 과정에서 생성된 파일은 사용자가 선택하거나 Shorts Studio가 지정한 로컬 저장 위치에 보관될 수 있습니다.

사용자는 Windows 파일 시스템을 통해 이러한 파일을 직접 이동하거나 삭제할 수 있습니다. Jun Soft는 로컬에 저장된 사용자의 프로젝트 파일을 원격으로 삭제하거나 관리하지 않습니다.

6. 개인정보의 판매 및 광고 목적 이용

Jun Soft는 Shorts Studio를 통해 처리되는 사용자의 개인정보나 프로젝트 데이터를 판매하지 않습니다. 또한 해당 데이터를 타깃 광고 목적으로 제공하지 않습니다.

7. 제3자 서비스

사용자가 Shorts Studio와 함께 외부 AI 서비스, 콘텐츠 생성 서비스, 클라우드 서비스 또는 기타 제3자 서비스를 사용하는 경우, 해당 서비스에서 처리되는 데이터에는 각 제3자의 개인정보처리방침이 적용됩니다.

Jun Soft는 제3자 서비스가 독립적으로 수집하거나 처리하는 정보에 대해서는 해당 서비스의 정책 범위를 넘어 통제하지 않습니다.

8. 아동의 개인정보

Shorts Studio는 아동을 대상으로 개인정보를 의도적으로 수집하는 서비스가 아닙니다. Jun Soft는 관련 법령에 따라 보호가 필요한 아동의 개인정보를 의도적으로 수집하지 않습니다.

9. 보안

Jun Soft는 개인정보 및 프로젝트 데이터의 불필요한 외부 전송을 최소화하고, 애플리케이션의 기능 수행에 필요한 범위 내에서만 데이터를 처리하도록 노력합니다. 사용자는 운영체제 및 보안 소프트웨어를 최신 상태로 유지하고 중요한 프로젝트 파일을 적절하게 백업하는 것이 좋습니다.

10. 정책 변경

Shorts Studio의 기능 또는 데이터 처리 방식이 변경되는 경우 본 개인정보처리방침이 업데이트될 수 있습니다. 중요한 변경 사항은 이 페이지의 시행일 또는 개정 내용을 통해 확인할 수 있도록 하겠습니다.
